# Arma3服务器查询

AstrBot 插件（标识符 `astrbot_plugin_arma3_query`）：在 QQ 群里查询 Arma3 服务器状态与全部在线玩家，
并支持服务器掉线自动播报、可自定义的入群欢迎语。

## 功能

- **查服务器** — 发服务器名，返回在线人数、地图、游戏版本、是否加密、连接地址，以及**全部**在线玩家（时长 / 得分，不做截断）
- **服务器列表** — 一条指令同时看到所有服务器的在线状态与人数
- **各群互相独立** — 每个群的服务器清单各自一份，互相看不到也改不到
- **掉线自动播报** — 服务器掉线 / 恢复时自动播报到所属群，只在状态变化时播报，不刷屏
- **入群欢迎** — 欢迎语可自定义，支持变量替换，自动 @ 新人让对方收到提醒
- **全指令管理** — 群主 / 群管理员在群里就能增删服务器、改欢迎语，不需要改代码

## 前置条件

| 项 | 要求 |
|---|---|
| AstrBot | `>= 4.10.0` |
| 消息平台 | **仅 OneBot v11**（aiocqhttp / NapCat / Lagrange 等），因为需要读取群成员身份 |
| 服务器端 | 需要开启 A2S 查询（Arma3 默认开启），无需安装任何服务端插件 |

> **查询端口**：Arma3 默认 `steamQueryPort = 游戏端口 + 1`。插件里填**查询端口**，输出的连接地址会自动取「查询端口 − 1」。

## 安装

1. 在 WebUI 的插件市场搜索 **Arma3服务器查询** 安装，或把本目录放进 `data/plugins/`
2. 重启或重载插件（`requirements.txt` 里的依赖会自动安装）
3. **装完第一件事**：打开「插件配置」，把 **机器人主人的 QQ 号**（`owner_qq`）填上

> 没填 `owner_qq` 时，插件可以正常查询，但「添加白名单 / 删除白名单 / 白名单」这三个主人专属指令不会生效，
> 也不会把任何陌生人误当成主人。日志里会有相应提示。

## 指令

**所有人可用**

| 指令 | 说明 |
|---|---|
| `help` / `帮助` | 查看指令说明 |
| `服务器列表` | 列出（本群 / 私聊为全部群）服务器，附带在线状态 |
| `<服务器名>` | 查询该服务器；玩家列表全部列出 |

**仅机器人主人**（需先配置 `owner_qq`）

| 指令 | 说明 |
|---|---|
| `添加白名单` | 在当前群授权使用本插件 |
| `删除白名单` | 取消当前群的权限 |
| `白名单` | 查看已授权群列表 |

**群主 / 群管理员（私聊时仅主人）**

| 指令 | 说明 |
|---|---|
| `添加服务器 IP>查询端口>名称` | 例：`添加服务器 123.123.123.123>2303>arma1` |
| `覆盖服务器 IP>查询端口>名称` | 覆盖同名服务器的地址与端口 |
| `删除服务器 名称` | 例：`删除服务器 arma1` |
| `欢迎` | 查看本群欢迎语与开关状态 |
| `欢迎 开` / `欢迎 关` | 打开 / 关闭本群入群欢迎 |
| `设置欢迎语 <内容>` | 设置本群专属欢迎语 |
| `清除欢迎语` | 恢复使用面板里的默认欢迎语 |

**私聊说明**：私聊是只读总览，可以查询和列出**所有群**的服务器，但**不能增删**——
增删必须到对应的群里做，避免写错群。

## 入群欢迎

欢迎语支持以下变量，发送时自动替换：

| 变量 | 含义 |
|---|---|
| `{昵称}` | 新人 QQ 昵称（取不到时回退群名片 / QQ 号） |
| `{群名片}` | 新人群名片（没设置时等同昵称） |
| `{QQ}` | 新人 QQ 号 |
| `{群号}` | 本群群号 |
| `{群名}` | 本群群名 |
| `{人数}` | 本群当前成员数 |
| `{时间}` | 发送时的时分，如 `09:30` |

设置后会先回一遍「实际发送效果」给你确认。示例：

```
设置欢迎语 欢迎加入本群！
本群是 Arma3 服务器交流群，发送「服务器列表」查看在架服务器。
有问题随时 @管理员
```

> 每个群可以单独设置，互不影响；没单独设置的群使用面板里的默认模板。
> 因为发送时会自动 @ 新人，默认文案里没有再写 `{昵称}`——想写也可以，只是会显示成「@张三 欢迎 张三 加入」。

## 配置项

| 配置项 | 默认 | 说明 |
|---|---|---|
| `enable_group_whitelist` | `false` | 是否启用群白名单，默认关闭（装好即可用） |
| `allowed_groups` | `[]` | 白名单群号列表 |
| `owner_qq` | `""` | 机器人主人 QQ，**建议安装后立即填写** |
| `welcome_enabled` | `false` | 入群欢迎总开关（默认关闭，属主动发消息功能，需自行开启） |
| `welcome_at_newcomer` | `true` | 欢迎时是否 @ 新人 |
| `welcome_template` | 见默认值 | 默认欢迎语 |
| `query_cooldown` | `5` | 普通群友查询冷却秒数，`0` 表示不限制（主人不受限） |
| `watchdog_enabled` | `true` | 掉线 / 上线播报开关 |
| `watchdog_interval` | `180` | 巡检间隔秒数，范围 60–3600 |

## 常见问题

**查询失败 / 超时？**
先确认三件事：服务器确实开着、填的是**查询端口**（不是游戏端口）、服务器防火墙放行了 **UDP**。
插件给的提示会区分「没响应」「端口被拒」「不是 Arma3 的查询格式」。

**在线人数有，但玩家列表是空的？**
部分服务器关闭了 A2S_PLAYER 查询。此时插件会显示「玩家列表获取失败，只显示在线人数」，不影响使用。

**入群欢迎没发出来？**
看 AstrBot 日志里有没有 `[Arma3查询] 已发送入群欢迎`：
有 → 发送环节问题；没有 → NapCat 那边没把 `group_increase` 通知报上来。

**掉线播报没收到？**
确认 `watchdog_enabled` 是开的，并且那个群已经录入了服务器。首次巡检只记录状态不播报（避免重启刷屏），
状态发生变化时才会发消息。

**两个群想查同一台服务器？**
请在两个群里各添加一次。清单是按群隔离的，这正是为了互不干扰。

## 数据与隐私

所有数据只保存在本地插件数据目录，不联网上传任何内容：

```
data/plugin_data/astrbot_plugin_arma3_query/
├── servers.json     各群的服务器清单
└── welcome.json     各群单独的欢迎语
```

插件会访问公网 IP 查询接口（用于显示服务器的公网连接地址），仅用于获取本机出口 IP，不做其他用途。
